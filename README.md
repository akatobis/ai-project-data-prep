# AI Project Data Preparation

## Описание проекта

Репозиторий содержит неструктурированные данные трёх модальностей
(текст, изображения, аудио) для обучения ИИ-модели автоматической
категоризации и извлечения ключевых сущностей из сообщений,
возникающих в процессе разработки ИИ-проектов.

## Структура репозитория

- `data/text/` — текстовые данные: GitHub Issues, Stack Overflow, arXiv
- `data/images/` — изображения: схемы архитектур, скриншоты интерфейсов
- `data/audio/` — аудиозаписи: лекции, доклады, интервью
- `code/` — скрипты для сбора и обработки данных
- `docs/` — документация: инструкции, глоссарий, источники
- `presentation/` — презентация лабораторной работы

## Источники данных

| Модальность | Источник | Ссылка |
|---|---|---|
| Текст | GitHub Issues | https://github.com |
| Текст | Stack Overflow | https://stackoverflow.com |
| Текст | arXiv.org | https://arxiv.org |
| Изображения | Публикации, документация | Открытые источники |
| Аудио | Открытые курсы, подкасты | Открытые источники |

## Описание кода

- `github_issues_parser.py` — сбор issues из репозиториев ML-проектов
- `stackoverflow_parser.py` — сбор вопросов по тегам ML/NLP
- `arxiv_parser.py` — сбор аннотаций статей
- `text_cleaner.py` — очистка текста от HTML, лишних символов
- `image_resizer.py` — приведение изображений к единому размеру
- `audio_converter.py` — конвертация аудио в формат WAV 16kHz
